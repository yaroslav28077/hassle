# Перенос сборки ONEAS STUDIO (Radmir RP) на HASSLE 2.0 — окружение для агента в Antigravity

Это готовая рабочая папка: промпт агента, правила, скиллы по фазам и скрипты конвейера. Агент в Google Antigravity сам читает `AGENTS.md`, правила из `.agents/rules/` и скиллы из `.agents/skills/`.

## Что внутри

```
AGENTS.md                 главный промпт агента (роль, фазы, ворота, формат отчётов)
.agents/rules/            правила: границы, порядок в папке, соглашения UE, качество ассетов
.agents/skills/           12 скиллов: env-check → recon → map / build-options → convert / rebuild-ui → ue-import → package → qa-release
tools/                    скрипты: инвентарь, TXD→PNG, IMG-распаковка, DFF→FBX (Blender), звук, разведка игры,
                          карта ассетов, модульная сборка .pak v12 (build_mod.py, pak_v12.py), конфигуратор
                          (configurator.py), импорт в UE, cook/pak, модульный установщик (make_installer.py)
docs/                     конвейер, справка по форматам и разбор UI ONEAS (oneas_ui_changes.md)
build_options.yaml        опции и пресеты модульной сборки (basic / maximum / custom)
mapping/asset_map.csv     таблица «файл сборки → ассет HASSLE» (с option_group / option_value и хэшами)
config.example.yaml       шаблон путей
PROGRESS.md               журнал, который ведёт агент
```

## Подготовка (один раз, ~30 минут)

1. Установи:
   - **Python 3.11+** (галочка «Add to PATH»), потом в папке: `pip install -r requirements.txt`
   - **ffmpeg** (сборка для Windows)
   - **Blender 4.2+** и в нём расширение **DragonFF** (Edit → Preferences → Get Extensions → DragonFF → Install)
   - **FModel** (для просмотра путей ассетов игры)
   - **Unreal Engine** нужной версии ставь после фазы 2, когда агент узнает версию игры
2. Скопируй `config.example.yaml` → `config.yaml` и впиши пути:
   - `source.build_dir`: папка со сборкой ONEAS. Лучше распакованный архив сборки: тогда агент сразу видит только её файлы. Можно и установленный Radmir со сборкой, агент сам отделит файлы сборки от файлов игры, но это дольше и надёжнее с чистой копией Radmir в `source.radmir_dir`;
   - `game.install_dir`: папка HASSLE 2.0;
   - пути к ffmpeg и Blender.
   Копировать ничего не нужно, агент только читает эти папки.
4. Открой папку в Antigravity (File → Open Folder). Проверь в панели Customizations, что видны 4 правила и 12 скиллов.

## Первое сообщение агенту

> Прочитай AGENTS.md и PROGRESS.md. Начни с фазы 0 (env-check), потом фазы 1 и 2. После фазы 2 остановись и покажи отчёт.

Дальше агент идёт по фазам и сам останавливается на воротах (после разведки игры, после карты соответствий, перед публикацией).

Совет по модели: для фаз 1–3 и разбора ошибок лучше самая сильная модель (Gemini Pro / Claude), для массовой конвертации хватит быстрой.

## Важно

- Агент не обходит шифрование, подпись паков и античит. Если HASSLE 2.0 шифрует контент, он остановится на фазе 2 и предложит варианты.
- Переносится только внешний вид и звук. Никаких изменений, дающих преимущество.
- Модифицированные файлы в онлайн-игре могут противоречить правилам проекта. Проверь правила HASSLE.
