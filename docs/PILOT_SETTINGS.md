# Пилот v6: внутриигровые «Настройки ONEAS»

Сборка: `out/release/zzz_OneasPort_0.1.0.zip` (один пак `zzz_OneasPort_P.pak` + пустые `.utoc/.ucas`, 127 файлов).
Внешний вид варианта ONEAS = одобренная v5. Нового в пилоте: переключение в игре.

## Установка
1. Закрыть игру. Удалить старые паки мода (`uninstall.bat` от v5 или вручную все `zzz_OneasPort*` из `Content\Paks\~mods`).
2. Распаковать архив, запустить `install.bat` (сам найдёт игру, попросит права администратора).

## Что проверить (≈10 минут)
| # | Действие | Ожидание |
|---|---|---|
| 1 | Зайти в игру | HUD как в v5 (ONEAS), в правом верхнем углу маленькая полупрозрачная шестерёнка |
| 2 | ESC | Внизу списка кнопка «Настройки ONEAS» |
| 3 | Нажать её | Меню паузы закрывается, поверх HUD панель «Настройки ONEAS», есть курсор, кириллица читается (не `□□□`) |
| 4 | «Радар» -> «Родной» | Сразу родной круглый радар HASSLE, без остатков прямоугольного |
| 5 | «Спидометр» -> «Родной» (лучше сидя в машине) | Родной спидометр HASSLE, без дублей |
| 6 | «Верхний HUD» -> «Родной» | Родной правый верх HASSLE |
| 7 | Вернуть всё на «ONEAS» | Снова как v5, без дублей и дыр |
| 8 | «Безопасный режим» -> «Вкл» | Весь HUD родной; «Выкл» — снова ONEAS |
| 9 | «Закрыть» | Панель исчезает, курсор пропадает, управление камерой работает |
| 10 | Выставить, например, родной радар, выйти из игры полностью, зайти снова | Радар остался родным (= `localStorage` в Cohtml сохраняется) |
| 11 | Открыть чат (T) и нажать шестерёнку | Открывается та же панель |

Скриншоты нужны для пунктов 3, 4, 7, 10. Если что-то не так — скриншот + что нажимали.

## Если сломалось
ESC -> «Настройки ONEAS» -> «Безопасный режим», или `uninstall.bat`. Стабильная v5 лежит в ветке `v5-stable`.

## Проверено до выдачи (превью в Chromium, Full HD)
- оба варианта каждой группы рендерятся, 6 циклов переключения всех групп без ошибок и без роста DOM;
- безопасный режим, сброс, сохранение в `localStorage` и восстановление после перезагрузки;
- кнопка в меню ESC открывает панель; `node --check` для Hud.js и PauseMenu.js;
- SHA-1 файлов внутри пака совпадают с проверенными.
Не проверено (только в игре): шрифты Cohtml, `localStorage` Cohtml, клик по шестерёнке с игровым курсором, 21:9/32:9.
