# Фаза 4: интерфейсы и HUD (Cohtml UI без UE)

Главный принцип: в HASSLE 2.0 интерфейс работает на **Cohtml** (Vue/Vite), а его файлы лежат в `.pak` как обычные файлы (`HassleOnline/Content/UserInterface/...`), а не как `uasset`. Поэтому переносим их **прямой подменой файлов в `.pak` по точному пути**, без импорта в UE и без cook.

1. Источники в сборке ONEAS: картинки (`png/svg`), шрифты, звуки UI (`uiresources/sounds/`), а также текстуры из TXD (`models/hud.txd`, `MobileHud/mobilescs.txd`), если они подменяют экраны/иконки/фоны.
2. Для каждого экрана/раздела (`hud`, `interfaces`, `speed`, `weapon`, `gps`, `LoadingScreen`) составь сопоставление в `mapping/asset_map.csv` (и заметку в `work/ui/<экран>.md`): целевой путь в `HassleOnline/Content/UserInterface/...` → файл сборки → размер/формат.
3. **Прямые совпадения (PNG/JPG/SVG/MP3/WAV):** проверяй пропорции и размер с оригиналом из HASSLE; SVG при необходимости подгоняй viewBox/размеры, PNG — с корректной альфой без каймы.
4. **Изменения оформления в CSS/JS/HTML** (если ONEAS менял цвета, расположение или стили через `JsLoader.asi`, а не только картинки): аккуратно переноси стили/цвета/шрифты в соответствующие CSS/HTML-ресурсы Cohtml, **не ломая JS-логику и биндинги с игрой**. Если правка требует изменения игровой логики/событий — ставь `blocked: нужна логика`.
5. **Шрифты:** проверяй лицензию на встраивание (см. `30-asset-quality.md`). При замене шрифтов в `LoadingScreen/fonts` или `Main/assets` следи за совпадением имён или @font-face в CSS.
6. **Экраны загрузки (`LoadingScreen` / `mobilescs.txd`):** подгоняй 4K/16:9 фоны под формат целевых картинок (`LoadingScreen/img/...` или соответствующие фоны в `Main/`).
7. **Прицелы и текстуры, которые в HASSLE сделаны как `uasset` (если такие найдутся в IoStore):** идут отдельно через `convert-textures` → `ue-import`.
8. Результат складывай в `work/ui_pak/HassleOnline/Content/UserInterface/...` с точной структурой путей для прямой упаковки в `zzz_OneasPort_P.pak` (без UE и без cook). Для ключевых экранов делай превью «было/стало» в `work/previews/ui_<имя>.png`.
