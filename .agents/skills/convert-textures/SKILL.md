# Фаза 4: текстуры

1. Извлечение: `python tools/txd_extract.py source work/textures` (и для `work/extracted`, если были .img). Манифест: `work/textures/manifest.csv`.
2. Ошибки в логе:
   - «платформа N не поддержана»: это не ПК-TXD (PS2/Xbox/Android), такие файлы помечай `blocked`.
   - «формат не поддержан»: допиши ветку в `_raw_to_image` (формат в `docs/FORMATS.md`).
3. Подгонка под слот HASSLE (только для строк с `target_package`): напиши скрипт `work/fit_textures.py` на Pillow:
   - целевой размер = размер оригинала из `game_ref/originals/` (если есть), иначе ближайшая степень двойки ≥ исходника;
   - вписывание с сохранением пропорций, прозрачные поля;
   - ресайз `LANCZOS`; для пиксельных элементов (рамки, иконки 1:1) `NEAREST`;
   - исправление каймы: для пикселей с alpha=0 подставь цвет ближайшего непрозрачного (dilate), чтобы не было тёмного ореола после сжатия.
   Результат: `work/textures_fit/<id>.png`, обнови `converted_file` в карте.
4. Контактный лист: собери `work/previews/textures_sheet.png` (сетка 8×N: исходник | подогнанный | оригинал HASSLE) и покажи пользователю для P1.
5. Статусы → `todo` (готово к импорту).
