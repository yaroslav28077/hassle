# Фаза 2: разведка HASSLE 2.0

1. `python tools/check_target.py` (путь к игре из `config.yaml`).
   Если пользователь дал папку со сторонней сборкой HASSLE для изучения формата:
   `python tools/check_target.py --mods "<путь>"`.
2. Прочитай `game_ref/target_report.md` и разбери вердикт.

## Если вердикт 🔴 (зашифровано или подписано)
- **СТОП.** Не ищи ключи, не пробуй обходить подпись, не трогай exe. Это правило из `00-guardrails`.
- Изучи, как устроены сторонние сборки (по `--mods`): какие типы файлов они кладут и куда. Иногда моды ставятся не через паки (конфиги, папки с картинками, официальный механизм). Если найден такой открытый путь, опиши его.
- Сообщи пользователю варианты: официальная поддержка модов или SDK, вопрос разработчикам HASSLE, перенос только тех частей, что ставятся открытым способом.

## Если вердикт 🟢
1. Запиши в `config.yaml`: `game.project_name`, `ue.engine_major`, версию движка в комментарий, `game.mods_subdir` (если в Paks уже есть `~mods` или сторонние сборки кладут туда; иначе `~mods`).
2. Пользователь ставит Unreal Engine **той же версии** через Epic Games Launcher.
3. Пути ассетов игры:
   - если индекс паков не зашифрован, открой их в **FModel** (выбери ту же версию UE) и выгрузи список путей нужных папок (UI, HUD, Weapons, Sounds, Vehicles) в `game_ref/asset_paths_<папка>.txt`;
   - сделай экспорт PNG/WAV оригиналов только для сравнения размеров и громкости (в `game_ref/originals/`, в пак не идёт).
4. Формат IoStore: если есть `.utoc/.ucas`, упаковка идёт режимом `iostore` (см. skill `package-pak`).

Отчёт пользователю + **СТОП**: версия UE, имя проекта, формат, шифрование, античит, куда ставим мод. Дальше только после «ок».
