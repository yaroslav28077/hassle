# Фаза 7: проверка и релиз

1. Напомни пользователю про риск для аккаунта (правило 00-guardrails, п.6).
2. `python tools/make_installer.py` → `out/release/zzz_OneasPort_<версия>/` + zip.
3. Пользователь запускает `install.bat`, заходит в игру. Чек-лист (`out/qa/checklist.md`):
   - [ ] игра запускается, нет вылетов 15 минут;
   - [ ] HUD: радар, HP/еда/броня, логотип, ID/онлайн;
   - [ ] прицелы на всех типах оружия, центр совпадает с точкой попадания;
   - [ ] каждый перенесённый интерфейс открывается и выглядит как в сборке;
   - [ ] звуки оружия (одиночный и автоматический огонь), громкость как у остальных звуков;
   - [ ] модели: масштаб, текстуры, нет розовых/чёрных материалов;
   - [ ] FPS не просел больше чем на 5% (сравнить с оригиналом);
   - [ ] `uninstall.bat` полностью возвращает оригинал.
4. Скриншоты до/после пользователь кладёт в `out/qa/`. По ним ставь `verified` в карте. Не ставь `verified` без подтверждения.
5. `out/release/CHANGELOG.md`: версия, что перенесено (по частям сборки), что нет и почему (из `skip`/`blocked`), известные проблемы. Перегенерируй релиз, чтобы changelog попал в архив.
6. **СТОП** перед публикацией: публикует пользователь (с упоминанием ONEAS STUDIO по договорённости).
7. После обновления HASSLE: заново `check_target.py`. Если сменилась версия UE или пути ассетов, мод пересобирается (импорт в проект новой версии → cook → pak).
