# Соглашения Unreal Engine для этого мода

- **Версия движка совпадает с игрой до минорной версии** (например 5.3 → только 5.3). Cooked-ассеты другой версии игра не загрузит или вылетит. Версию берём из `game_ref/target_report.md`.
- **Имя UE-проекта мода = имя проекта игры** (папка рядом с `Content/Paks` в установке игры, например `HASSLE/Content/Paks` → проект `HASSLE`). Так пути cooked-файлов и mount point совпадут с игрой.
- **Подмена = тот же путь пакета.** Чтобы заменить ассет игры `/Game/UI/HUD/T_Radar`, создаём в проекте мода ассет ровно с этим путём и именем и тем же классом (Texture2D → Texture2D).
- **Новые ассеты** (которых нет в игре) кладём в `/Game/Mods/OneasPort/...`. Сами по себе они в игре не появятся без кода, поэтому почти всегда нужна именно подмена.
- **Заглушки (dummy).** Если наш ассет ссылается на ассет игры (материал, скелет), создаём в проекте пустую заглушку по тому же пути, но **не включаем её в пак**. В пак идут только строки из `asset_map.csv`.
- Префиксы новых ассетов: `T_` текстура, `M_`/`MI_` материал/инстанс, `SM_` static mesh, `SK_` skeletal mesh, `S_`/`SW_` звук, `WBP_` виджет, `F_` шрифт.
- Текстуры UI: `TextureGroup = UI`, `CompressionSettings = UserInterface2D (TC_EditorIcon)`, `MipGen = NoMipmaps`, `sRGB = on`, размер степенью двойки, если оригинал игры тоже степень двойки.
- Текстуры мира: `World`, `Default (DXT1/5)`, мипы включены. Нормали: `TC_Normalmap`, `sRGB = off`.
- Пак мода называется `zzz_OneasPort_P.pak` (буквы `zzz` и суффикс `_P` = высший приоритет загрузки).
