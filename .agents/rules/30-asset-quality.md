# Качество ассетов

## Текстуры
- Извлекай верхний мип в PNG без потерь, с альфой. Не пережимай в JPG.
- Размер подгоняй под размер **оригинального ассета HASSLE** (если известен). Апскейл больше чем в 2 раза помечай в `notes` как «низкое разрешение исходника».
- Сохраняй пропорции. Если пропорции не совпадают с целевым слотом, делай подложку (padding) прозрачным, а не растягивай.
- Для элементов HUD/прицелов проверяй альфу: края без белой/чёрной каймы (premultiplied → straight).

## Модели
- GTA SA работает в метрах, UE в сантиметрах. При импорте FBX проверяй масштаб на первом ассете (машина ≈ 450 см в длину, оружие ≈ 60–120 см).
- Ось: проверь на пилотном ассете, что модель смотрит вперёд по +X в UE. Подобранные настройки запиши в `PROGRESS.md` и используй дальше.
- Число и имена слотов материалов должны совпадать с оригиналом HASSLE, иначе материалы слетят.
- Skeletal mesh (персонажи, руки) переносится только на скелет игры (заглушка того же пути). Если иерархия костей отличается, ставь статус `blocked` и описывай, не пытайся подогнать.
- Коллизии GTA (`.col`) не переносим: в UE используется коллизия оригинального ассета.

## Звук
- WAV PCM 16-bit, 48 кГц, моно для 3D-звуков (выстрелы, попадания), стерео для UI и музыки.
- Нормализация громкости к уровню оригинальных звуков HASSLE (замер на 2–3 образцах). Без клиппинга.
- Длина и момент атаки (transient) выстрела должны совпадать с оригиналом, иначе звук будет «отставать».

## Интерфейсы
- Интерфейсы Radmir (HTML/CSS/картинки, CEF) напрямую в UMG не переносятся. Основной путь: подмена текстур, которые использует UI HASSLE, на картинки из сборки (тот же размер, тот же путь).
- Пересборка виджетов (WBP) с другой вёрсткой возможна только если они не завязаны на код игры. По умолчанию не делаем: ставим `blocked` с пометкой «нужна логика».
- Шрифты: переносим только если у шрифта есть лицензия на встраивание. Иначе `skip`.
